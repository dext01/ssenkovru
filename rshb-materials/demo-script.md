# Демонстрация «Мой дом»

Файл: demo.webm. Длительность контейнера — 2:46,84. Формат: WebM/VP9, 1280×720, 25 кадров/с; без звука. Поясняющие титры добавлены в запись поверх интерфейса, они не являются функцией продукта.

Все финансовые данные учебные. Записаны фактические действия в браузере на публичной клиентской версии. Изменение заголовка администратором сохранено только в изолированном браузере записи; сайт для других посетителей не изменялся.

## Воспроизведение

Откройте index.html из пакета или demo.webm в браузере с поддержкой WebM. Для передачи без доступа к репозиторию приложите весь contest-submission.zip.
